# CareerOS - Project Context

## Project Name

CareerOS

---

## Vision

CareerOS is an AI-powered interview preparation platform that helps software engineers prepare for interviews using personalized learning.

The platform analyzes a user's resume, identifies skill gaps, generates a learning roadmap, creates daily interview questions, evaluates answers using AI, tracks progress, and sends Telegram notifications.

---

## MVP Features

- Authentication
- Resume Upload
- AI Resume Analysis
- Skill Gap Analysis
- Learning Roadmap
- Daily Questions
- AI Answer Review
- Progress Dashboard
- Telegram Notifications
- Scheduler

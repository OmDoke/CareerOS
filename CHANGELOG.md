# Release Strategy

CareerOS follows Semantic Versioning.

```
MAJOR.MINOR.PATCH
```

Example

```
1.0.0

│ │ │
│ │ └── Bug Fix
│ └──── Feature
└────── Breaking Change
```

---

# Release Types

## Patch Release

Example

```
1.0.1
```

Changes

- Bug fixes
- UI improvements
- Performance improvements

---

## Minor Release

Example

```
1.1.0
```

Changes

- New feature
- Backward compatible
- Small improvements

---

## Major Release

Example

```
2.0.0
```

Changes

- Breaking API changes
- Major redesign
- Large architecture updates
